---
name: Application capacity policy
description: Agreed distinction between available places and incoming applications.
---

Capacity limits accepted students, not the number of applications. Pending and
under-review applications do not reserve places. Once all places are filled,
new applications stop; existing pending applications are not automatically rejected.

**Why:** The user explicitly selected the accepted-only capacity rule so staff
can receive applications and choose participants without overbooking.

**How to apply:** Preserve this distinction in submission rules, review actions,
capacity edits and labels. Do not change to first-come place reservations without
asking the user.
