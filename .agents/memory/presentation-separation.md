---
name: Presentation separation
description: Keeps presentation work from changing or visually confusing the Involv website.
---

Build and revise school-facing presentations as separate artifacts. Do not modify the Involv website when the requested work is presentation-specific.

**Why:** The user explicitly wants the website and presentation to remain distinct, with the deck available separately in chat for viewing or download.

**How to apply:** Make slide content, assets, previews, exports, and workflow changes only inside the presentation artifact unless the user explicitly asks for a website change.
